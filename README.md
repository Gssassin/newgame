# 青春的抉择 (Choices of Youth)

> 大学恋爱  成长叙事  多周目视觉小说

##  简介
《青春的抉择》是一部以大学新生入学为起点的生活向视觉小说。
你将扮演主角**林川**（默认名/可自定义），从高考后的志愿填报开始，走进中国矿业大学的校园。在这里，你将体验真实的大学生活：宿舍夜聊、食堂干饭、图书馆占座、社团招新

在日常的点滴与关键的抉择中，你会遇见活泼开朗的**苏雨晴**与优雅淡定的**江诗韵**。是追求学术巅峰，还是成为社交达人？是在这个夏天谈一场轰轰烈烈的恋爱，还是专注于自我成长？
一切答案，都由你来书写。

##  游戏特色
- **多样的成长路线**：
  - **专业选择**：计算机 / 经管 / 数学，不同的专业将带来不同的课程体验。
  - **社团活动**：文学社 / 篮球社 / 建模协会，解锁不同的剧情分支。
- **丰富的属性系统**：
  - 管理你的 **学习、社交、创造力、体力** 和 **金钱**。
  - 不同的属性值将影响剧情走向和结局判定。
- **好感度系统**：
  - 通过日常互动和特殊事件提升女主角的好感度。
  - 攻略对象：苏雨晴、江诗韵。
- **沉浸式校园体验**：
  - 包含宿舍、教学楼、食堂、图书馆、篮球场等多个真实校园场景。
